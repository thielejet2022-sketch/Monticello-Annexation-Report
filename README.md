# Monticello Annexation Report

Public repository for source-grounded research, reports, corrections, and evidence indexes concerning the City of Monticello annexation and related Mine Lake matters.

## Publication standard

- Issued reports are preserved as published.
- Corrections are issued as separately dated addenda.
- Material changes are proposed through pull requests.
- Claims are distinguished as documented fact, inference, allegation, or unresolved question.
- Sensitive, personal, privileged, or unreviewed source material is not published here.

## Repository structure

- `reports/` - issued investigative reports
- `addenda/` - dated corrections and clarifications
- `sources/` - publication-safe evidence indexes and source notes
- `working/` - sanitized analytical work that is not yet an issued finding

See `AGENTS.md` for research and change-control rules and `CHANGELOG.md` for the publication history.
