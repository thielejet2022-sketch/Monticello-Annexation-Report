# Sources and Evidence Index

This directory contains publication-safe source notes and evidence indexes.

Before adding a source, record:

| Field | Description |
|---|---|
| Evidence ID | Stable identifier, such as `AUDIT-2019-001` |
| Title | Full document title |
| Date | Document or publication date |
| Origin | Producing agency, publication, or custodian |
| Location | Public URL or controlled-storage reference |
| SHA-256 | Hash of the retained source file, when applicable |
| Relevant pages | Pages or sections supporting the finding |
| Publication status | Public, withheld-sensitive, or pending review |
| Notes | Authentication, limitations, or relationship to a finding |

Do not place sensitive or unreviewed records in this public repository.
